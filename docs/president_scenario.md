# Steel Tide — 「다음 장: 대통령 출마」 시나리오 초안

> 국방부장관 임기를 마치고 민간인이 된 주인공이 대통령 선거에 나서는 단계.
> 정당·후보·인물은 모두 가상이며, 실제 정당이나 정치인을 그리지 않는다. 수치는 모두 게임용 값이다.
> 실제 선거 제도를 빌려 온 부분은 "제도 모티브"로 표시했다. 세부 날짜·기간은 구현 전에 공식 자료(중앙선거관리위원회)로 확인할 것.

---

## 0. 한 줄 요약

장관 시절의 성적(지지율·사업·위기 방어율)이 **인지도와 안보 이미지**로 넘어오고, 민간인 프롤로그 → 출마 결심·정당 선택 → (당내 경선) → 3주 본선 → TV 토론 3회 → 선거일 밤 개표로 이어진다. 당선되면 취임식 연출과 함께 "대통령(국군통수권자)" 단계를 예고하고, 낙선하면 민간인으로 남거나 2회차로 간다.

---

## 1. 이어받는 것 (국방부장관 → 대통령 출마)

| 장관 기록 | 출마 단계에서 바뀌는 값 |
|---|---|
| 평균 국정 지지율 | 시작 **인지도** (평균 60이면 인지도 45, 1점당 ±1) |
| 완성한 LV5 사업 수 | **정책 신뢰** +5/개 (공약 발표 효과 ↑) |
| 다해역 위기 방어율 | **안보 이미지** (80% 이상이면 "안정감" 특성) |
| 명예 퇴임 여부 | 정당 영입 제안이 1개 더 옴 |
| 결재 안건에서 고른 입장 (전작권·9·19·확성기 등) | TV 토론·기자회견에서 **"과거 발언 검증"** 질문으로 다시 나옴. 입장을 바꾸면 신뢰 −, 지키면 해당 지지층 + |

장관 때 내린 결정이 선거에서 되돌아오게 만드는 것이 핵심 재미.

## 2. 단계 구성

### 프롤로그 · 민간인 (4턴, 1턴 = 2주)
- 화면: 집무실 대신 **개인 서재/사무실** (새 배경 필요).
- 매 턴 활동 하나 선택:
  - 회고록 출간 — 인지도 +6, 자금 +
  - 대학·안보 포럼 강연 — 안보 이미지 +, 청년층 +
  - 싱크탱크 설립 — 정책 신뢰 +, 자금 −
  - 지역 방문 (지도에서 권역 선택) — 해당 권역 지지 +
  - 휴식 — 체력 회복
- 4턴째 끝에 **출마 결심 장면**(기자회견 장면 재사용): 「출마 선언」/「불출마」. 불출마면 민간인 엔딩.

### 1단계 · 정당 선택
가상 정당 3개 + 무소속.

| 선택 | 장점 | 단점 |
|---|---|---|
| **청람당** 입당 (원내 1당, 가상) | 조직·자금 큼 | 당내 경선 필수, 경쟁자 2명 |
| **한울당** 영입 (원내 2당, 가상) | 경선 약식(여론조사 1회), "영입 인사" 보너스 | 당 지지 기반 작음 |
| **무소속** | 경선 없음, 중도·무당층 + | 조직·자금 매우 적음, 단일화 이벤트 필요 |

정당 성향은 일부러 이념 좌표로 그리지 않고 **정책 우선순위(안보/경제/복지/청년/지역균형)** 가중치로만 구분한다.

### 2단계 · 당내 경선 (청람당·한울당 루트)
- 권역별 순회 경선 4회: 충청 → 호남·제주 → 영남 → 수도권·강원.
- 매 회차: 연설 주제 선택 + 경선 토론 1문항(장면) + 조직 동원 배분.
- 결과 = 당원 투표 50% + 일반 여론조사 50% (게임 규칙, 실제 정당 규정과 다를 수 있음).
- 가상 경쟁자 2명 (예: "도시 행정형" 시장 출신, "경제통" 전 장관). 각자 강점 권역이 다름.
- 탈락 시: 승복(다음 회차 NG+ 보너스) / 탈당 후 무소속 출마(조직 −, 화제성 +).

### 3단계 · 본선 (공식 선거운동 약 3주, 1턴 = 3일, 7턴)
> 제도 모티브: 후보 등록 후 정해진 공식 선거운동기간이 있음. 정확한 일수는 공식 자료 확인.

매 턴 할 일 (국방부 집무실 UI 틀을 재사용):
1. **유세 일정** — 한반도 지도(워룸 지도 재사용)에서 권역 2곳 선택. 권역별 유권자 구성이 다름.
2. **공약 카드** — 매 턴 1장 발표. 공약 5분야(안보·경제·복지·청년·지역균형) 각 3단계. 장관 시절 완성한 사업과 같은 분야면 "실적 있는 공약" 보너스.
3. **선거 결재판** — 매 턴 안건 2~3건 (장관 결재판과 같은 구조, 연출 토글 그대로 적용).
4. **자금 배분** — TV 광고 / 온라인 / 현장 조직.
5. **체력** — 유세를 몰아치면 떨어지고, 0이면 실언 이벤트 확률 ↑.

유권자 모델 (가상 집단, 지역·세대·관심사):
- 안보 관심층 / 경제 관심층 / 청년층 / 중도·무당층 / 고령층
- 권역 6개: 수도권, 충청, 호남, 영남, 강원, 제주
- 후보 지지율 = Σ(집단 비중 × 집단별 호감) + 무작위 오차. 매 턴 **여론조사 결과**를 오차 범위와 함께 보여 준다.

### 4단계 · TV 토론 3회 (2·4·6턴째)
> 제도 모티브: 대통령 선거에는 선거방송토론위원회 주관 법정 토론이 있음 (횟수는 확인 필요).

- 새 장면 종류 `debate`: 스튜디오 배경, 상대 후보 2명, 사회자.
- 한 회당 질문 4개: 주제 질문 2 + **상대 후보 공격 1** + **과거 발언 검증 1**(장관 시절 결재 기록에서 뽑음).
- 답변 유형: 정책으로 반박 / 실적 강조 / 역공 / 인정·사과. 유형마다 집단별 반응이 다르다.
- 토론이 끝나면 "토론 직후 여론조사" 카드와 언론 평가 헤드라인 3개 연출.

### 5단계 · 선거일 밤
- 제도 모티브: 사전투표, 선거일 직전 여론조사 공표 금지 기간.
  - 마지막 2턴은 여론조사 숫자가 가려지고 "깜깜이" 표시만 나온다.
- 연출 컷:
  1. 투표소 (아침)
  2. 캠프 상황실 — 출구조사 발표 카운트다운
  3. 개표 그래프 — 실시간 득표율 선, 권역별 지도 색칠
  4. 당선 확실 / 낙선 인정 연설 (장면, 답변 선택: 승복 연설 톤)
- 결과:
  - **당선**: 취임식 연출 (함대 사열 이미지 재사용 + 새 취임식 배경) → "대통령 · 국군통수권자" 단계 예고
  - **낙선**: 민간인 엔딩 → 명예의 전당 기록, 2회차 선택

## 3. 선거 결재판 안건 예시 (실제 선거 양상을 모티브로 한 가상 사건)

| 안건 | 선택지 예시 | 효과 방향 |
|---|---|---|
| 후보 단일화 제안 (무소속·소수당 후보) | 수용 / 조건부 협상 / 거절 | 지지 합산 vs 화제성·원칙 이미지 |
| 상대 캠프의 네거티브 의혹 제기 | 법적 대응 / 정면 해명 기자회견 / 무대응 | 신뢰·체력·지지 |
| 장관 시절 결정 재조명 기사 | 입장 유지 / 사과 / 맥락 설명 | 안보 관심층 ↔ 중도층 |
| 접경지역 도발 발생 (선거 중 안보 위기) | 정부에 초당적 협조 / 정부 대응 비판 / 현장 방문 | 안보 이미지 크게 변동 |
| 가짜 뉴스·딥페이크 영상 유포 | 선관위 신고 / 팩트체크 공개 / 무시 | 신뢰·청년층 |
| 청년 일자리 공약 재원 논란 | 재원 세부안 공개 / 공약 축소 / 강행 | 정책 신뢰 vs 청년층 |
| 지역 숙원 사업 약속 요청 | 약속 / 검토 / 거절 | 해당 권역 + vs 재정 신뢰 − |
| 캠프 내부 인사 갈등 | 정리 / 중재 / 방치 | 조직력 |
| 말실수 영상 확산 (체력 낮을 때) | 즉시 사과 / 해명 / 반박 | 지지 − 크기 조절 |

## 4. 필요한 새 배경 이미지 (제미나이 생성용 목록)

모두 16:9, 1376×768 이상, 인물은 가상 인물로 생성.

1. 퇴임 후 개인 서재·사무실 (책, 노트북, 창밖 저녁)
2. 출마 선언 기자회견장 (현수막 문구 없이, 태극기·단상)
3. 당내 경선 체육관 연설회장 (객석, 응원 피켓 — 실제 정당 로고 없이)
4. 거리 유세 차량과 군중 (낮, 지방 도시 시장 앞)
5. TV 토론 스튜디오 (후보 3명 단상, 사회자석)
6. 캠프 상황실 (화이트보드, 여론조사 그래프, 참모들)
7. 투표소 (기표소, 투표함)
8. 선거일 밤 개표 방송을 보는 캠프 (대형 TV, 긴장한 표정)
9. 당선 확정 순간 캠프 (환호, 꽃가루)
10. 대통령 취임식 (국회 앞마당 같은 야외 단상, 군 의장대) — 실제 행사 사진처럼 특정 인물 없이
