# THE GENERAL — 진급 과정 정밀화 기획안 (Promotion Refinement Plan)

> **목적**: 다른 에이전트 또는 개발자가 바로 구현할 수 있도록, `THE GENERAL`의 장교 진급 시스템을 실제 한·미 군 인사체계(진급심사위원회 / Promotion Board) 수준으로 정밀화하기 위한 상세 설계서입니다.
> **전제 조건**: 한 계급당 기본 복무 기간 **10주 이상**(`minWeeks`: 위관 10주 / 영관 12주 / 장성 14주) 및 계급별 맞춤 주간 직무·훈장·보직 정리 완료 상태를 기반으로 확장합니다.

## 1. 핵심 문제 진단 (As-Is)

1. **수시 랜덤 진급 판정**
   - 현재 `runBoard()`([app/public/js/service.js](file:///C:/Users/June/.gemini/antigravity/scratch/steel-tide/app/public/js/service.js))는 XP·근무횟수·복무주차가 충족되면 주간 직무나 전투 1회를 끝낼 때마다 **즉시 랜덤 판정**을 수행한다.
   - 문제점: "심사 시즌을 준비한다"는 긴장감이 없고, 운이 나쁘면 같은 주 안에서 연달아 누락되어 급작스럽게 계급정년 전역할 위험이 있다.
2. **군내 평판(`d.rep`)과 부대 사기(`d.morale`)의 진급 미반영**
   - `duty.js`에서 매주 관리하는 `rep`(군내 평판)과 `morale`(부대 사기)가 정작 진급 심사 공식에는 반영되지 않는다.
3. **계급 구간별 관문(허들) 차별화 부족**
   - 소위→중위나 대령→준장(별 달기)이나 같은 백그라운드 확률식으로 처리되며, 지휘관 경력(Command Tour)과 합동·참모 경력(Joint Staff Tour)의 균형 요구가 없다.
4. **임관·사관학교 동기의 실질 경쟁 부재**
   - 동기 2명이 지휘 계통도(조직도)에 고유 보직으로 배치되어 있으나, 진급 심사 TO(정원) 경쟁이나 상호 협조/견제 이벤트가 아직 연결되지 않았다.

## 2. 목표 아키텍처 (To-Be)

### 2.1 정기 진급심사 시즌 (Quarterly Promotion Board)
- **주기**: 매 **4주차(4주, 8주, 12주…)** 끝 또는 복무기간(`rankWeeks >= minWeeks(g)`) + XP 충족 시 **「정기 진급심사위원회 상정」** 버튼/모달 활성화.
- **준비 기간**: 심사 2주 전부터 상단에 `진급심사 D-2주` 예고 배너 표시 → 플레이어가 평판 관리·핵심 직무·위기 직접 개입으로 점수를 끌어올릴 전략적 타이밍 제공.
- **기수(차수) 제한**: 영관(소령~대령) 이상은 최대 **3기수(1차·2차·3차 정기심사)** 도전 가능. 1기수당 1회만 판정하므로 1주 내 연속 누락 버그 원천 차단.

### 2.2 진급 심사 채점표 고도화 (100점 만점 + 동기 경쟁)

| 항목 | 배점 | 계산 기준 | 데이터 소스 |
|---|---:|---|---|
| **근무평정** | 40점 | 현 계급 평균 평정 (`evalOf(g).avg`, 55~100점 선형 환산) | `career.evals[g]` |
| **보직 트랙** | 25점 | 요직(`key`): +25 / 일반(`std`): +15 / 한직(`back`): +5 + **지휘/합동 균형 보너스(+5)** | `staff.js` `postTier()` + `career.tours` |
| **군내 평판** | 20점 | `d.rep` (0~100 → 0~20점) | `duty.js` `dutyState().rep` |
| **전공·훈장** | 15점 | 현 계급 위기 직접 개입 승리(+5/회) + 보유 훈장 가산 | `career.medals`, `career.crisisWins` |
| **감점 요인** | -10~0 | 감찰 적발 이력(`auditFail`), 부대 사기 35 미만 지속 | `duty.js` |

- **합격 기준선**:
  - 위관(소위~대위): **55점 이상 자동 진급** (결격 사유 없을 시)
  - 영관(소령~대령): **68점 이상** (대령→준장은 **76점 이상 + 장성 TO 경쟁**)
  - 장성(준장~대장): **78점 이상 + 빈 상위 보직 TO 확보**

### 2.3 지휘 경력(Command) vs 합동·참모 경력(Joint/Staff) 균형 시스템
- `career.tours = { cmd: 0, joint: 0, edu: false }` 추가.
  - 야전 지휘 보직(대대장·함장·비행대대장·여단장·사단장 등) 1계급 완수 시 `tours.cmd++`
  - 합참·국방부·펜타곤·정책/획득 보직 완수 시 `tours.joint++`
- **장성(준장/O-7) 진급 시**:
  - 한국군: 야전 지휘관 경력 1회 이상 권장 (미달 시 심사 -8점)
  - 미군: **골드워터-니콜스법(Goldwater-Nichols Act)** 반영 — 합동참모(Joint) 또는 고등군사교육(War College) 미이수 시 심사 -10점

### 2.4 계급 구간별 전용 관문(Milestone Events)
1. **위관 → 영관 (대위 → 소령 / O-3 → O-4)**:
   - 초급 지휘관 평가 종합 + 영관 보직 트랙(야전 지휘 vs 합동/정책 참모) 분기 선택.
2. **영관 → 장성 (대령 → 준장 / O-6 → O-7, "별 달기")**:
   - **한국군**: 「국방부 장성인사심사 & 삼정검 수여식」 2단계 연출.
   - **미군**: 「상원 군사위원회(SASC) 장성 인준(Confirmation)」 3문항 약식 질의응답(기존 `scene.js` 재활용).
3. **3성 → 4성 (중장 → 대장 / O-9 → O-10)**:
   - 현재 공석인 4성 보직 목록(동기가 이미 차지한 자리는 `[동기 재임 중]` 표시) 중 **희망 보직 1지망**을 선택해 심사에 상정.

### 2.5 보직 선택 시 인사 참모 코멘트 (은근한 요직/한직 힌트)
- 진급 명령서 3페이지(`renderPostPick`)에서 `postTier(title)`의 내부 점수를 직접 노출하지 않고, 현실적인 인사 참모 코멘트 1줄만 표시:
  - `key`: *"핵심 지휘·전략 보직 — 업무 강도가 높으나 상급 진급 심사에서 높게 평가됩니다."*
  - `std`: *"표준 직무 보직 — 안정적인 경력 관리와 평정 유지에 적합합니다."*
  - `back`: *"지원·교육 계통 보직 — 부대 사기 관리에 유리하나 야전 지휘 경력 비중은 낮습니다."*

## 3. 신규 연계 콘텐츠 설계

### 3.1 진급심사위원회(Promotion Board) UI 모달
- 정기 심사 시점 도달 시 `사령부 → 주간 직무` 상단에 **`🏛️ 제N차 정기 진급심사위원회 소집`** 카드 표시.
- 클릭 시 전용 심사 모달 오픈:
  1. 서류 심사 4개 항목(근무평정 / 보직 트랙 / 군내 평판 / 전공·훈장) 순차 체크 애니메이션
  2. **(영관·장성)** 같은 계급 동기 2명과의 **TO 경쟁 현황판** 표시 (예: `이번 기수 준장 진급 TO: 2석 / 후보: 나, 동기1, 동기2`)
  3. 최종 결과 발표 → 합격 시 기존 `buildPromo()` 인사명령서로 자연스럽게 전환 / 누락 시 `N차 누락` 사유 요약(예: *"군내 평판 부족"*, *"야전 지휘 경력 미흡"*) 제공

### 3.2 임관·사관학교 동기 인터랙션 이벤트
- `duty.js`의 `rivals` 객체에 `rel: 50` (관계도 0~100) 필드 추가.
- 6~8주마다 1회 동기 이벤트 발생:
  - **합동작전/예산 공조**: 동기의 작전·예산안을 지지(관계도 +15, 내 평판 +3) vs 내 부대 우선 확보(관계도 -12, 내 평정 +5)
  - **진급 경쟁 견제**: 상급부대 브리핑에서 동기 성과 공유 vs 단독 보고
- **후반 보상**: 관계도 75 이상인 동기는 내가 4성(참모총장) 또는 국방장관(SecDef)이 되었을 때 **핵심 참모/차장 기용 보너스** 및 지지율·예산 통과율 보정 제공.

### 3.3 군 고등교육 과정 파견 (소령~대령 선택 이벤트)
- 한국군: **합동군사대학교 / 국방대학교 안보과정**
- 미군: **Command & General Staff College / National War College**
- 선택 시 2주간 현장 직무 대신 학술·전략 세미나 이벤트 진행 → 수료 시 `career.tours.edu = true` 획득(장성 진급 가산점 +8, 군내 평판 +6).
