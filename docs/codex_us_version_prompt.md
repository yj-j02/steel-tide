# Codex 작업 프롬프트 — Steel Tide 미국 버전(US Edition)

> 아래 전체를 Codex에 붙여 넣으세요. (저장소 루트의 `AGENTS.md`를 Codex가 자동으로 읽습니다.)

---

## 작업 개요

저장소 `yj-j02/steel-tide`의 현대전 **한국편 커리어**(장교 → 국방부장관 → 대선 → 대통령)를 바탕으로 **미국 버전**을 만든다. 엔진(장면 연출·결재판·선거·표결·지도·관리자 바)은 재사용하고, 제도·지도·문구·수치는 미국 것으로 바꾼다.

먼저 `AGENTS.md`, `README.md`, `docs/president_scenario.md`를 읽는다. 그다음 `js/ministry.js`, `js/president.js`, `js/potus.js`, `js/scene.js`, `client.js`의 해당 부분을 읽고 구조를 파악한다.

## 작업 방식

- 브랜치 `us-edition`에서 작업하고 PR로 올린다. `main` 직접 push, `gh-pages` 배포, 파일 삭제는 하지 않는다.
- 아래 **결정 사항**은 사용자가 정한 값이 없으면 **추천안**으로 진행하고, PR 설명 맨 위에 체크리스트로 적는다.
  1. 구조 (추천): 한 게임 안에서 시작 시 "대한민국 / United States"를 고르는 방식. 다른 안은 별도 사이트로 분리.
  2. 언어 (추천): 미국편 UI는 영어, 시스템 메시지는 영어. 다른 안은 한국어 UI에 고유명사만 영어.
  3. 가상 정당 이름 (추천): `Union Party`(파랑) / `Liberty Party`(빨강) — 실제 정당 이름 금지, 규칙·수치 대칭.
  4. 재선 (추천): 4년 임기 후 재선 출마 선택 가능, 최대 2선.
  5. 지도 범위 (추천): 인도·태평양 (한반도·대만해협·남중국해·괌·일본).
- 인터넷 조회가 안 되는 환경이면 제도 세부값을 추측해서 넣지 않는다. `TODO(확인 필요)` 상수로 두고 PR에 목록을 적는다.

## 1단계 — 내용 분리 리팩터링 (한국편 동작 불변)

- 안건 표·문구·수치·이미지 이름을 나라별 데이터 모듈로 뺀다.
  - 대상: `ministry.js`, `president.js`, `potus.js`의 `DOCKET`, `DEBATE_Q`, `PROLOGUE`, `PLEDGE_LV`, `AGENDA`, `CRISES`, `SUMMIT`, 정당·지역·집단 표 등
  - 파일: `js/content/kr.js`, `js/content/us.js`
- 엔진 함수는 공용으로 두고, `region`(`"kr"`/`"us"`)에 따라 데이터를 고른다.
- 저장 키는 미국편만 `steeltide:us:*`로 분리한다. 한국편 키와 기존 저장 데이터는 그대로 둔다.
- 관리자 바로 한국편 장관 → 대선 → 대통령 → 엔딩을 돌려서 바뀐 게 없는지 확인한다.

## 3단계 — 미국편 구현

- `content/us.js`에 넣을 것:
  - 장관 결재 안건 30건 이상
  - 대선 결재 안건 10건 이상
  - 토론 질문 (경제·사회·외교안보)
  - 국정 안건 14건 이상
  - 위기 5종
  - 정상회담 대상
- 새 메커니즘:
  - 상원 인준 청문회 (장관 시작 시 장면 연출 1회)
  - 경합주 지도 (주별 선거인단, 유세지 선택)
  - 선거인단 집계 연출
  - 양원 표결 + 거부권 + 필리버스터
  - 중간선거
  - 재선 출마
- 장면 연출: `scene.js`의 `SHOTS`, `FB`, `THEMED`에 미국 이미지 이름(`us_*`)을 추가한다.
  - 이미지가 아직 없으니 `FB`로 기존 사진을 대신 쓴다.
  - 단 한국 대통령 얼굴이 보이는 사진(`address_*`, `president_office_*`)은 미국편 대체 사진으로 쓰지 않는다.
- 내 정보·상단 바: 미국 계급명, Secretary of Defense, President 직함, 가상 대통령 표장(SVG로 직접 그림).
- 관리자 시험 바를 미국편에도 단다:
  - 인준 통과
  - 경선 승리
  - 선거일 이동
  - 당선·낙선
  - 의석 조정
  - 분기 건너뛰기
  - 엔딩

## 4단계 — 밸런스 시뮬레이션 (Node 헤드리스)

| 단계 | 목표 |
|---|---|
| 장관 | 잘하는 플레이는 임기 목표 대부분 달성, 대충 하면 실패 |
| 대선 | 잘하면 당선 약 90%, 보통 약 30% |
| 대통령 | 잘하면 '성공/안정' 엔딩, 대충 하면 '평범/레임덕' |

시뮬레이션 스크립트는 `tools/sim/`에 넣고, 수치를 PR에 표로 적는다.
