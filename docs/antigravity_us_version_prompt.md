# Antigravity 프롬프트 — Steel Tide 미국 버전 만들기

> 「인계 프롬프트」(antigravity_handoff_prompt.md)를 먼저 읽힌 뒤, 아래 전체를 이어서 붙여 넣으세요.

---

Steel Tide의 현대전 **한국편 커리어**(장교 → 국방부장관 → 대선 → 대통령)를 바탕으로 **미국 버전(US Edition)**을 만든다. 게임 시스템은 그대로 쓰고, 나라·제도·지도·인물·텍스트를 미국 것으로 바꾸는 작업이다.

## 0. 시작 전에 사용자에게 체크리스트로 물을 것 (만들기 전에 꼭)

1. **구조**
   - (A) 한 게임 안에서 시작할 때 "Korea / United States"를 고른다 (추천)
   - (B) 별도 사이트로 분리한다
2. **언어**
   - 미국 버전 UI를 영어로 할지
   - 한국어로 하되 고유명사만 영어로 할지
3. **가상 정당 이름 2개**
   - 실제 정당 이름은 쓰지 않는다.
   - 색은 파랑·빨강을 그대로 쓸지, 중립색(예: 청록·주황)으로 할지
4. **대통령 임기 구성**
   - 4년 1회만 플레이할지
   - 재선 출마(최대 2선)까지 넣을지
5. **지도 범위**
   - 인도·태평양 전역 (한반도·대만해협·남중국해·괌)
   - 서태평양만

답을 받은 뒤 진행한다. 결정하지 못한 부분은 추천안으로 진행하고 보고에 적는다.

## 1. 기본 원칙

- **코드는 하나, 내용은 나라별로 분리한다.**
  - 지금 `ministry.js`, `president.js`, `potus.js` 안에 들어 있는 안건·문구·수치 표를 나라별 데이터 모듈로 뺀다.
    - 예: `js/content/kr.js`, `js/content/us.js`
  - 엔진 함수는 공용으로 남긴다.
  - 한국편 동작은 바뀌면 안 된다. 분리 후 한국편을 처음부터 끝까지 다시 돌려 확인한다.
- **저장 키를 나라별로 나눈다.**
  - 예: `steeltide:us:mod`
  - 한국편 진행과 섞이지 않게 한다.
- **실존 인물 금지.** 모든 인물은 가상이고, 실존 정치인과 닮은 이미지도 쓰지 않는다.
- 두 정당은 **규칙·수치 완전 대칭**으로 만든다. 이념 좌표나 지역 고정관념으로 차이를 두지 않는다. 정책 우선순위로만 구분한다.
- **실제 제도·사례를 쓸 때는 공식 출처로 확인하고 출처를 남긴다.** 확인 못 한 숫자·날짜는 넣지 말고 사용자에게 "확인 필요"로 보고한다.
- 대통령 문장(Seal of the President)은 쓰지 않는다. 사용이 법으로 제한된다는 점을 확인하고, 가상 표장을 만든다.

## 4. 작업 순서

1. **내용 분리 리팩터링**: 한국편 데이터를 `content/kr.js`로 빼고, 한국편 전체 흐름이 똑같이 동작하는지 확인한다. 관리자 시험 바로 장관 → 대선 → 대통령 엔딩까지 확인한다.
2. **미국 제도 조사**: 2장 표의 "확인할 것"을 공식 출처로 확인한다. 출처 목록을 `docs/us_research.md`에 남긴다.
3. **미국편 데이터**: `content/us.js`에 다음을 만든다.
   - 장관 결재 안건 30건 이상 (사례 모티브는 출처 있는 것만)
   - 대선 결재 안건
   - 토론 질문
   - 국정 안건
   - 위기 목록
4. **새 메커니즘**:
   - 상원 인준 청문회
   - 선거인단 계산과 경합주 지도
   - 양원·거부권·필리버스터 표결
   - 중간선거
   - 재선 출마 (선택 시)
5. **지도**: 인도·태평양 해안선 추출 (`js/indopac.js`). 같은 투영 함수 방식을 쓴다.
6. **밸런스 시뮬레이션**: 한국편과 비슷한 난이도로 맞춘다.
   - 장관: 잘하면 목표 달성
   - 대선: 잘하면 90%, 보통 30%
   - 대통령: 잘하면 '성공/안정'
7. **관리자 시험 바**를 미국편에도 똑같이 단다.
8. **검증**: 브라우저 자동화로 미국편 전체 흐름과 한국편 회귀를 확인한다. 콘솔 에러 0, 1280×720 / 1600×900 스크린샷을 남긴다.
9. **배포**: 인계 프롬프트의 배포 절차대로 한다. Higgsfield 배포는 사용자가 요청할 때만 한다.

## 5. 보고 형식 (한국어)

- 바꾼 것과 새로 만든 것을 표로 정리한다.
- 제도 확인 결과에는 출처와 신뢰도 표시를 단다.
- 시뮬레이션 수치를 적는다.
- 사용자가 결정해야 할 것은 체크리스트로 묻는다.
- 받아야 할 이미지 목록을 적는다.
