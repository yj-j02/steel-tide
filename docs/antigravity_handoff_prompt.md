# Antigravity 인계 프롬프트 — Steel Tide 이어서 개발하기

> 아래 전체를 Antigravity 에이전트에게 그대로 붙여 넣으세요.

---

너는 지금부터 웹 3D 해전 게임 **Steel Tide**의 개발을 이어받는다. 이전에는 다른 AI 에이전트가 개발했고, 기획은 사용자와 Gemini가 함께 했다. 사용자는 한국어로 대화하며, 결과를 직접 플레이해 보고 피드백을 준다.

## 1. 프로젝트 기본 정보

- 저장소: `github.com/yj-j02/steel-tide`, 작업 브랜치 `main`
- 테스트 서버: https://yj-j02.github.io/steel-tide/ (`gh-pages` 브랜치)
- 정식 배포(Higgsfield): https://steel-tide-naval.higgsfield.app — **사용자가 "배포해줘"라고 할 때만** 배포한다.
- 기술: three.js r170 (`app/public/vendor/three.module.min.js`, importmap 이름 `"three"`), 빌드 없는 순수 ES 모듈. 번들러·프레임워크를 추가하지 않는다.
- 로컬 실행: 저장소 루트에서 `python tools/serve.py 8852` → http://localhost:8852 (캐시 꺼짐, 소리 끔. `?sound`를 붙이면 소리 켜짐)
- 저장은 모두 브라우저 `localStorage` (`steeltide:*` 키). 서버·DB 없음.

## 2. 배포 절차 (커밋할 때마다)

1. `main`에 커밋하고 push
2. `app/public` 내용 전체 + 빈 `.nojekyll` 파일을 `gh-pages` 브랜치 루트에 넣고 force-push (gh-pages는 배포 전용 브랜치라 force-push가 원래 방식)
3. 커밋 메시지는 한국어로, 무엇을 왜 바꿨는지 쓴다

## 3. 반드시 지킬 규칙 (사용자 규칙)

- 사용자에게는 **한국어**로 답한다.
- 사실 관계 답변 끝에 신뢰도 표시: `[신뢰도 높음]` / `[신뢰도 보통 — 확인 필요]` / `[신뢰도 낮음 — 사용 전 확인 필수]`
- **출처를 지어내지 않는다.** 실제 사례를 모티브로 쓸 때는 확인 가능한 출처가 있을 때만 "실제 사례 모티브"라고 표시한다.
- 스스로 판단해 진행하고 결과를 보고하되, **모르겠으면 만들기 전에 사용자에게 묻는다.**
- 확인할 게 여러 개면 하나씩 묻지 말고 **체크리스트 한 번**으로 묻는다.
- **PC 전용** 게임이다. 모바일 대응을 하지 않는다.
- **키보드 단축키는 건드리지 않는다.**
- **스텝 메뉴(단계 메뉴)는 유지**한다.
- 관리자 코드는 `hydro` (프로필 `admin: true`). 관리자 전용 기능은 일반 플레이에 보이면 안 된다.
- 코드 스타일: 한 줄짜리 문장 **중간에 `//` 주석을 넣지 않는다.** 줄 중간 주석은 `/* */`, 줄 끝 주석만 `//`.
- **API 키·비밀번호를 게임·저장소에 넣지 않는다.** (예: Typecast 음성 API 키는 사용자 PC에만 있다. 채팅으로 받지도 않는다.)
- **실존 인물을 그리지 않는다.** 정치인·장관·대통령·기자 등 모든 인물은 가상이다. 실존 인물과 닮아 보이는 이미지는 쓰지 말고 사용자에게 알린다.
- 정당은 가상 정당 **민주함께당(파랑)·한누리당(빨강)** + 무소속. 두 정당은 **규칙·수치가 완전히 대칭**이다. 이념·지역 고정관념으로 차이를 두지 않는다.

## 4. 게임 구조 (현대전 한국편 커리어)

소위 임관 → 진급·보직 → 대장 → **국방부장관(50주)** → 민간인 → **대통령 선거** → **대통령(20분기)** 으로 이어지는 커리어 게임이다. 전투는 3D 해전과 2D 작전지도(FM 스타일).

### 파일 지도 (`app/public`)

| 파일 | 역할 |
|---|---|
| `index.html` | 모든 CSS와 DOM 패널 (스타일은 전부 여기) |
| `client.js` | 메뉴, 전투 설정, HUD, 사령부 탭, 내 정보, 얼굴 생성(`face`, `agedFace`), 각 모드 화면 연결 |
| `js/opmap.js` | 작전지도(해상·항공 시나리오, 결정 이벤트, 캠페인 「서해 72시간」, 작전 후 기자회견) |
| `js/ministry.js` | 국방부장관 모드: 결재판(실제 사례 모티브 안건 약 39건), 교리, 방위력 개선 사업, 합동 워룸 한반도 지도, 긴급 NSC, 지지율·예산 그래프, 이임식 연출, 역대 장관 갤러리, 2회차(NG+) |
| `js/president.js` | 대통령 선거: 민간인 프롤로그 4턴 → 정당 선택 → 출마 선언 → 당내 경선 4회 → 본선 7턴(유세·공약·결재) → 법정 TV 토론 3회 → 여론조사 공표 금지 → 선거일 밤 |
| `js/potus.js` | 대통령 모드: 20분기, 국무회의 결재, 국회 300석 표결(협상/강행), 국정 과제 5개, 정상회담, NSC 위기(작전지도는 **보기 전용** 상황도, 직접 지휘 불가), 3년차 총선, 임기 평가 엔딩·탄핵 엔딩 |
| `js/scene.js` | 실사 이미지 연출 엔진: `openScene`(질문·답변 장면), `playCuts`(나레이션 컷), `setTheme`(정당 색 이미지 선택), 없는 이미지는 `FB` 표로 대체 |
| `js/korea.js` | 한반도 해안선 경로 (Natural Earth 50m, 퍼블릭 도메인) + `kxy(경도, 위도)` 투영 |
| `img/bg/*.jpg` | 장면 배경 사진 (AI 생성, 1376×768) |
| `img/potus_mark.png` | 대통령 표장 (대통령일 때 계급장 대신 표시) |
| `docs/president_scenario.md` | 대선 시나리오 기획서 |

### 저장 키

`steeltide:profile`, `career`, `cmdr`, `staff`, `camp`, `oplog`, `c72`, `mod`(장관), `hall`(역대 장관), `legacy`, `pres`(대선), `potus`(대통령), `potus_hall`(역대 대통령), `scenes`(연출 on/off)

### 장면 연출 규칙

- 결재 연출은 사용자가 껐다 켤 수 있다(`steeltide:scenes`). 꺼져 있으면 장면 대신 결재판에서 바로 고른다.
- 새 배경 사진은 `img/bg/이름.jpg`로 넣으면 바로 쓰인다. 정당 색 사진은 `이름_blue.jpg` / `이름_red.jpg` (대상: declaration, primary_hall, rally, election_night, victory).
- 장면 초점 좌표는 `scene.js`의 `SHOTS` (이미지 안 0~1 비율 좌표 + 확대 배율).

## 5. 관리자 시험 기능

관리자일 때 국방부 집무실·대선 캠프·대통령실 상단에 빨간 「관리자 시험」 바가 뜬다. 장관 즉시 퇴임, 대선·대통령 바로 시작, 경선 승리, D-3 이동, 당선·낙선, 지지율·예산·의석 조정, 위기·정상회담 발생, 4분기 건너뛰기, 엔딩 확인. 새 모드를 만들면 같은 방식으로 시험 버튼을 추가한다.

## 6. 밸런스 기준 (시뮬레이션으로 맞춘 값)

- 국방부장관 50주: 잘하는 플레이 임기 목표 달성 ~100%, 보통 ~80%, 대충 0%
- 대선: 정당 후보로 잘하면 당선 90%+, 대충 하면 ~30%, 무소속은 잘해도 35~40%
- 대통령: 잘하면 '성공/안정' 엔딩, 대충 하면 '평범/레임덕'
- 수치를 바꾸면 **헤드리스 시뮬레이션(Node로 모듈을 import하고 localStorage를 흉내)을 직접 만들어 수백 판 돌려 보고** 결과를 사용자에게 보고한다.

## 7. 검증 방법

- 브라우저 자동화(Playwright 등)로 실제 클릭 흐름을 끝까지 돌리고 스크린샷을 확인한다. 1280×720, 1600×900 두 크기.
- 콘솔 에러 0개를 확인한다.
- 화면 글자가 칸 밖으로 넘치거나 겹치지 않는지 스크린샷으로 본다.

## 8. 지금 남아 있는 일

1. **배경 이미지 정리 (사용자 확인 필요)**: `img/bg/address.jpg`, `img/bg/president_office.jpg`는 실존 전직 대통령과 닮아 보여서 빼야 하는 이미지다. 지우기 전에 사용자에게 확인받고 지운다. 같은 폴더의 `*_dm.jpg`, `*_hn.jpg`는 코드에서 쓰지 않는 중복본이다(정리 대상, 이것도 확인 후 삭제).
2. 다시 받아야 할 배경 4장: 대통령 집무실(파랑·안경 쓴 가상 대통령 / 빨강·안경 안 쓴 가상 대통령), 대국민 담화(파랑 / 빨강). 받으면 `president_office_blue/red.jpg`, `address_blue/red.jpg`로 넣고 `scene.js`의 `THEMED`에 추가한다.
3. 대통령 모드 NSC 위기 때 "작전지도 보기 전용(관전)"을 실제 작전지도 관전으로 확장할지 사용자에게 묻는다(지금은 한반도 상황도만 보여 준다).
4. 그 밖의 새 기획은 사용자(또는 Gemini 기획서)를 기다린다.

## 9. 일하는 방식

- 작업 시작 전에 저장소를 받아 `README.md`, 이 문서, `docs/president_scenario.md`를 읽는다.
- 큰 변경 전에는 계획을 짧게 보여 주고, 결정이 필요한 부분은 체크리스트로 묻는다.
- 끝나면 한국어로 짧게 보고: 무엇을 바꿨는지(표로), 어떻게 검증했는지, 신뢰도 표시.
